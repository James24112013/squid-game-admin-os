# Squid Game Administration OS

A dark, dystopian administration dashboard inspired by the Squid Game universe.

## Features
- Player search terminal
- Staff database
- Security camera dashboard
- Game and round management overview
- Facility map and room assignment display
- Contestant tracker and rankings
- System logs and operational feed

## Run locally
Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
